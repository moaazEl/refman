# Refman 0.1.0 — friends beta

A local reference and source organiser for Apple Silicon Macs, with editable Word citations, Griffith APA 7 reference formatting and readable project backups.

Includes DOI/URL metadata import, projects and assignment briefs, notes and attachments, parenthetical/narrative/multiple-source citations, explicit reference inclusion, manual corrections, Word update safeguards, DOCX export, an advisory citation audit, version restoration, and Light/Dark/Follow Mac appearance.

Download **Refman-0.1.0-mac-arm64.zip** below. Unzip it, drag Refman.app to Applications, and read START-HERE.txt. Microsoft Word for Mac is needed for direct Word integration. Intel Macs, Windows and phones have no supported ready-made build in this release.

This is an unsigned, non-notarised beta. Follow Apple's first-launch guidance only if you trust the download. Live ChatGPT sign-in/summaries/corrections remain unverified and are optional; each user needs their own eligible account. No API key is requested. Existing organisation, citation, Word and backup checks have passed; see docs/TESTING.md.

Known limits: no automatic cloud merging or app updates; unusual reference types require review; full claim-support verification and physical second-Mac testing remain outstanding.
